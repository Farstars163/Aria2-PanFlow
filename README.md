#  项目名称：Aria2-PanFlow

### **1. 项目简介**

本项目是一款专为“懒人”打造的网盘下载增强工具。它深度集成了 **LinkSwift** 的直链解析能力与 **Aria2** 的高速多线程下载技术。

* **核心逻辑**：在不破坏网盘原有限速规则的前提下，通过**极大化并发线程数**与**服务器连接数**，充分榨干带宽潜力，实现下载提速。
* **交互设计**：UI 界面参考了备受好评的 **Motrix**，力求简洁、美观且易于操作。

---

### **2. 项目核心特点**

#### ** 多平台深度支持**

项目针对不同网盘的协议进行了适配，目前支持以下平台：

| 网盘平台     | 预期下载速度 | 备注                      |
| :----------- | :----------- | :------------------------ |
| **百度网盘** | 1 - 200 KB/S | 适合小文件                |
| **夸克网盘** | 1 - 2 MB/S   | 速度较为稳定              |
| **阿里云盘** | ~100 KB/S    | 依赖解析接口稳定性        |
| **123网盘**  | **高速下载** | 非会员每月享有 10G 流量包 |

#### ** 功能亮点**

* **直链下载器**：可作为单独的直链下载使用。
* **原生文件浏览**：直接调用网盘 API 获取目录树，无需跳转网页，在本地即可轻松浏览网盘文件。
* **批量推送技术**：支持单选或多文件勾选，一键将任务推送到 Aria2 后端，实现高效并发下载。
* **多语言接口集成**：主体基于 LinkSwift，部分网盘逻辑（123/阿里）采用 Python 实现（集成 `@Bao-qing` 和 `@aligo` 开源接口），兼顾了开发效率与功能覆盖面。

### **3. 快速上手指南**

#### **第一步：启动与登录**

* **启动项目**：双击运行 `start.bat`。
* **账号登录**：
  * **123网盘**：终端内会直接打印 **QR 登录码**，使用微信扫码即可。
  * **阿里云盘**：会自动弹出 **QR 登录图片**，使用阿里云盘 App 扫码即可。
  * *注：首次运行会生成 `pan123_token.json` 和 `aliyun_aria2.json`，请妥善保管，切勿泄露给他人。*

#### **第二步：停止与维护**

* **关闭项目**：双击运行 `stop.bat`，脚本将自动清理并结束所有关联进程，无后台残留。
* **异常处理**：
  * 若 **123网盘** 文件列表失效，请运行 `python_service/pan123_login.exe` 重新扫码。
  * 若**未成功**启动网页，请停止后重新运行。
  * **阿里网盘** 具备自动检测机制，Token 过期时会自动弹出登录验证。
